# stem-image-processing
# STEM-проєкт: Класичні методи обробки та аналізу зображень

Програмне рішення для порівняльного аналізу класичних методів обробки зображень (без використання бібліотек комп'ютерного зору та методів машинного навчання).

## Структура проєкту
* `config.json` — конфігураційний файл із параметрами алгоритмів та шляхами до директорій.
* `methods.py` — ручна реалізація 5 класичних методів обробки зображень (медіанний фільтр, гамма-корекція, оператор Прюітта, метод Оцу, морфологічний градієнт).
* `metrics.py` — ручне обчислення метрик якості зображень (`MSE`, `PSNR`, `SSIM`).
* `main.py` — головний модуль запуску обробки вибірки, генерації тестового шуму та збереження метрик у `CSV`.
* `test_methods.py` — модульні автотести для перевірки коректності алгоритмів на тестових матрицях 3×3.

## Встановлення та запуск

1. Встановіть необхідні залежності (використовуються лише для математичних обчислень та введення/виведення зображень):
```bash
pip install numpy pillow
```

2. Помістіть вибірку зображень у папку `dataset/` (або вкажіть власний шлях у `config.json`).

3. Запустіть обробку всіх зображень усіма методами:
```bash
python main.py --method all
```
Або запустіть конкретний метод (`median`, `gamma`, `prewitt`, `otsu`, `morph_grad`):
```bash
python main.py --method median
```

4. Запуск модульних тестів:
```bash
python -m unittest test_methods.py
```

## Результати
Після виконання у директорії `results/` зберігаються оброблені зображення по папках відповідних методів та зведений файл із метриками `results/metrics_report.csv`.
